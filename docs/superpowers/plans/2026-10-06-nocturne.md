# Nocturne 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 사이트를 Nocturne 어두운 전시실로 다시 만들고, 폰·PC 브라우저에서 사진을 올리면 AI(PC 12B, 없으면 GitHub e4b)가 바로 게시하며, 작은 모델이 쓴 설명은 PC가 나중에 12B로 다듬는 구조를 붙인다.

**Architecture:** 공개 저장소 `nocturne` 하나. 관리 페이지(바닐라 ES 모듈)가 사진을 브라우저에서 메타데이터 없는 사본으로 만들어 `queue/`에 커밋한다. PC 도우미와 Actions `draft.yml`이 같은 Python `Worker`로 대기 항목을 맡아 초안을 쓰고 한 커밋으로 게시한다. `site.yml`이 `build.py --out _site`로 Pages에 배포한다.

**Tech Stack:** Python 3.14 + Pillow, 표준 라이브러리 `urllib`/`http.server`/`unittest`, 브라우저 WebCrypto·Canvas, Node 24 `node --test`(테스트 전용), GitHub REST API, GitHub Actions, Ollama 0.35.1.

**Spec:** `docs/superpowers/specs/2026-10-06-nocturne-design.md` (개정 2)

**스펙 대비 정한 점**
- `name_for`에서 파일명이 비면 `"photo"`. 이름이 겹치면 `-2`, `-3`.
- 정규 `photos.json` 형식은 `tests/fixtures/site.canonical.json`으로 고정하고 Python·JS가 글자까지 같아야 한다.
- 로컬 시험용 **가짜 GitHub 서버**(`tests/fake_github.py`)로 관리 페이지·Worker를 끝까지 시험한다. 관리 페이지는 `localhost`에서 열렸을 때만 `?api=`를 쓴다.
- 관리 페이지 JS는 `admin/lib/`(DOM 없는 순수 모듈), `admin/views/`(화면), `admin/app.js`(시작·로그인·탭). 저장소 루트 `package.json`은 `{"private": true, "type": "module", "scripts": {"test": "node --test tests/js/"}}`.
- Python 대기열 모듈 이름은 표준 라이브러리 `queue`와 겹치지 않게 `queue_items.py`.
- 여러 장을 한꺼번에 올리면 PC는 한 틱에 한 장씩 맡으므로, 60초 안에 PC가 맡지 못한 나머지는 GitHub가 e4b로 게시하고 나중에 PC가 다듬는다 (속도 우선).

## Global Constraints

- Python 3.14, 의존성은 표준 라이브러리 + `Pillow>=11.3`. Node 24는 테스트에만. 관리 페이지는 빌드 단계 없는 바닐라 ES 모듈, 외부 스크립트 금지 (Google Fonts CSS만).
- 유료 API 금지. Ollama `http://127.0.0.1:11434`. 모델은 `NOCTURNE_MODEL` — PC 기본 `gemma4:12b-it-qat`, Actions `gemma4:e4b-it-qat`.
- 저장소 `HPotty36/nocturne`(공개) 하나, 브랜치 `main`. 대기열 경로 `queue/<name>/`.
- 실명 금지. 장소 이름 추측 금지. 문구는 한국어로 짧고 평이하게. alt는 한 문장, 흑백이면 끝에 "흑백 사진".
- 사람이 고친 제목·설명과 방 배정은 AI가 다시 바꾸지 않는다.
- 색은 토큰으로만. `--lamp`는 포커스·현재 방 표시에만.
- 저장소·사이트에 들어가는 사진은 메타데이터를 지운 사본뿐.
- 토큰은 URL에 넣지 않고 `https://api.github.com`(개발 중에는 `localhost`의 가짜 서버)으로만 보낸다. 관리 페이지 JS는 `innerHTML`, `outerHTML`, `insertAdjacentHTML`, `eval`, `new Function`을 쓰지 않는다.
- 커밋 메시지(정해진 문구): `대기열: <name> 올림` / `대기열: <name> 다시 시도` / `대기열: <name> 버림` / `대기열: <name> PC가 맡음` / `대기열: <name> GitHub가 맡음` / `대기열: <name> AI 실패` / `사진 게시: <제목>` / `AI 설명 다시 쓰기: <제목>` / `AI 설명 개선: <제목>` / `사진 수정: <제목>` / `사진 삭제: <제목>` / `대표 사진 변경: <제목>`.

```python
class DataTests(unittest.TestCase):
    def setUp(self):
        self.d = json.loads(json.dumps(helpers.SITE))
    def test_canonical_text(self):
        self.assertEqual(photolib.dumps_data(helpers.SITE), (helpers.FIXTURES / "site.canonical.json").read_text(encoding="utf-8"))
    def test_save_load_roundtrip(self):
        root = helpers.make_site(Path(tempfile.mkdtemp()))
        data = photolib.load_data(root); photolib.save_data(root, data)
        self.assertEqual(photolib.load_data(root), data)
        self.assertEqual(photolib.listed(data), {"a1", "a2", "n1"})
    def test_add_and_find(self):
        photolib.add_photo(self.d, "night", {"file": "n2", "title": "t", "alt": "a", "ai": photolib.ai_entry("m", 0.9)})
        room, p = photolib.find_photo(self.d, "n2")
        self.assertEqual((room["id"], p["ai"]), ("night", {"model": "m", "fields": ["title", "alt"], "confidence": 0.9}))
        self.assertNotIn("confidence", photolib.ai_entry("m", None))
        for bad in (("moon", "x"), ("night", "a1")):
            with self.assertRaises(photolib.PhotoError):
                photolib.add_photo(self.d, bad[0], {"file": bad[1], "title": "t", "alt": "a"})
        with self.assertRaises(photolib.PhotoError):
            photolib.find_photo(self.d, "zzz")
    def test_upgrade_rules(self):
        _, a2 = photolib.find_photo(self.d, "a2"); _, a1 = photolib.find_photo(self.d, "a1")
        self.assertTrue(photolib.needs_upgrade(a2, "gemma4:12b-it-qat"))
        self.assertFalse(photolib.needs_upgrade(a1, "gemma4:12b-it-qat"))
        self.assertFalse(photolib.needs_upgrade({"ai": {"model": "gemma4:e4b-it-qat", "fields": []}}, "gemma4:12b-it-qat"))
        a2["ai"]["fields"] = ["alt"]
        photolib.apply_ai_text(a2, {"title": "새 제목", "alt": "새 설명"}, "gemma4:12b-it-qat", ["alt"])
        self.assertEqual((a2["title"], a2["alt"]), ("다리 아래", "새 설명"))
        self.assertEqual(a2["ai"], {"model": "gemma4:12b-it-qat", "fields": ["alt"], "confidence": 0.61})
        self.assertFalse(photolib.needs_upgrade(a2, "gemma4:12b-it-qat"))
```

```python
def room_confidence(logprobs, room):
    if not logprobs:
        return None
    text = ""
    for lp in logprobs:
        if re.search(r'"room"\s*:\s*"?\s*$', text):
            if lp["token"].strip().lstrip('"').strip():
                tops = lp.get("top_logprobs") or [lp]
                p = sum(math.exp(t["logprob"]) for t in tops
                        if (s := t["token"].strip().lstrip('"').strip()) and room.startswith(s))
                return round(min(1.0, p), 3)
        text += lp["token"]
    return None
```
